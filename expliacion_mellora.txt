Para medir a eficacia deste código e poder comparalo con outras implementacións 
axudarémonos do timer SysTick que está integrado no core do procesador.

Tomamos entón coma unidade de medida os ticks do SysTick, como a frecuencia de este 
timer e a da CPU é a mesma, podemos consideralos ciclos de CPU.

Para o caso do main-c.c, é dicir, para o código proporcionado e que o compilador 
optimiza, a execución da función tarda uns 295 ciclos.

Debemos entón mellorar a implementación en ensamblador para reducir o número de ciclos.
Para comezar se nos fixamos no código o rexistro número 4 non está facendo nada realmente, podemos
fusionar 2 operacións movs en unha soa.

(movs	r4, #1 ) ----\	
		 =====>>> (movs r1, #1)	
(movs	r1, r4 ) ----/ 

Continuando coa optimización, simplemente aplicouse a estratexia de loop unrolling, de forma que reducimos
de forma considerable o número de iteracións do bucle. Reducir o número de iteracións é moi beneficioso pois
eso implica que se realizarán menos comparacións (cmp r2, #0), menos saltos (bne .L2) e menos restas (subs r2, #1). 

Desta forma simplemente ordenando un pouco o código en ensamblador, repetíndoo un número adecuado de veces 
e reducindo o número de iteracións, a eficiencia do noso programa aumentará significativamente.

A miña versión optimizada implementada inline en C é:

uint32_t reverse_int(uint32_t in) {
	uint32_t out;
	asm volatile (
	".syntax unified\n"
	
	"movs   r3, %[IN]\n"
        "movs   r2, #8\n"
        "movs   %[OUT], #0\n"
    "1:\n"
        "movs   r1, #1\n"
        "lsls   %[OUT], %[OUT], #1\n"      
        "ands   r1, r3\n"              
        "orrs   %[OUT], r1\n"        
        "lsrs   r3, r3, #1\n"           
	
        "movs   r1, #1\n"
        "lsls   %[OUT], %[OUT], #1\n"      
        "ands   r1, r3\n"              
        "orrs   %[OUT], r1\n"        
        "lsrs   r3, r3, #1\n"           
 
	"movs   r1, #1\n"
        "lsls   %[OUT], %[OUT], #1\n"      
        "ands   r1, r3\n"              
        "orrs   %[OUT], r1\n"        
        "lsrs   r3, r3, #1\n"           

        "movs   r1, #1\n"
        "lsls   %[OUT], %[OUT], #1\n"      
        "ands   r1, r3\n"              
        "orrs   %[OUT], r1\n"        
        "lsrs   r3, r3, #1\n"           

	"subs   r2, r2, #1\n" 
	"cmp    r2, #0\n"
        "bne    1b\n"
	
	: [OUT] "=l" (out)
	: [IN] "l" (in)

	: "r1", "r2", "r3", "cc"
	);
	return out;
}
